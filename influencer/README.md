# AI influencers

Профили виртуальных персонажей для Instagram Reels. Каждый YAML в `personas/` —
«библия» персонажа: история, внешность, голос, рубрики, правила и промпты для
генерации изображений с одинаковым лицом.

| Аккаунт | Персонаж | Ниша |
|---|---|---|
| @mira.eats.real | Мира Сато | Здоровье: осознанное питание |
| @sarah.zero.debt | Сара Беннет | Финансы: бюджет и выход из долгов |
| @chloe.dates.honestly | Хлоя Мартен | Отношения: свидания и самоуважение |

## Как пользоваться промптами
1. `image.identity_prompt` — неизменная часть, описывающая лицо. Используется в
   каждой генерации без правок.
2. Сначала генерируем `image.reference_shots` и отбираем 10–20 удачных кадров с
   одинаковым лицом — это референс-набор (для LoRA / character reference).
3. Для рилсов: `identity_prompt` + `style_prompt` + описание сцены.
4. `image.negative_prompt` добавляем всегда.

## Общие правила для всех персонажей
- В био пометка «AI-created character / virtual creator»; в Instagram включаем
  метку «AI info» на реалистичный ИИ-контент.
- Персонажи не выдают себя за врачей, финансовых консультантов или психологов.
- Никаких накруток, ботов и масс-фолловинга.
- Рекламу помечаем «Платное партнёрство».

## Сценарии
`scripts/<persona>.yaml` — готовые сценарии рилсов до 30 секунд. `location`
ссылается на `higgsfield.locations[].id` в профиле персонажа, `est_seconds`
посчитано по `speech_wpm` (темп из голосового запроса) с запасом на паузы.
