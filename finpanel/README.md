# Фин. панель — помощник-бухгалтер

Отдельная веб-панель с паролем для учёта двух направлений:

1. **Трафик** — перепродажа трафика: вебы → вы → реклы.
2. **Мой товар** — свой товар: лиды от вебов → оператор → отправка наложенным платежом → выкуп или невыкуп.

Плюс **помощник в чате** (Claude). Ему можно писать обычным текстом или кидать скрины, он сам предлагает, что внести. Записывает только после вашего «Подтвердить».

## Что считает

**Трафик**
- Связки веб → оффер → рекл. Ставки меняются с даты, старые дни считаются по старым ставкам.
- Рекл платит за апрув или за валидный лид. Вебу платите за апрув или за любой лид.
- **Гарант апрува** у каждого рекла (связки) свой. Он применяется к дням не новее позавчера: `оплата = max(апрувы, лиды × гарант%) × ставка`. Более свежие дни помечены «предв.».
- Видно, сколько дал гарант и какие связки в плюсе только за счёт него.
- **Балансы.** Рекл: получено минус отработано. Плюс — его неотработанная предоплата, минус — он вам должен. Веб: выплачено минус начислено. Плюс — вы заплатили вперёд, минус — вы должны.

**Мой товар**
- Заказ: товар, количество, сумма в сумах, доставка. Курс фиксируется в заказе.
- При выкупе: выручка, себестоимость, оператор (% от суммы, фиксируется в момент выкупа), налог %, доставка. Невыкуп возвращает товар на склад.
- Апрув %, выкуп %, прибыль с одного выкупленного заказа, **максимальная цена лида и апрува**, выше которой вы уходите в минус.
- **Склад**: остаток, в пути, расход в день, на сколько дней хватит, предупреждение «пора докупать».
- **Курьерка**: сколько собрано наложкой и ещё не перечислено.
- Вебы те же, что в трафике, но **баланс по товару отдельный**.

**Общее**
- Прочие расходы (сервер, программист и т.п.): по направлению или общие.
- Главная: в плюсе вы или в минусе за любой период — по прибыли (начисления) и по кассе (реальные деньги), плюс все предупреждения.

## Установка на сервер

Нужен VPS с Docker (Ubuntu 22.04+, 1 ГБ RAM хватит) и домен (или поддомен).

1. В DNS домена создайте **A-запись** на IP сервера, например `fin.вашдомен.com`.
2. На сервере:
   ```bash
   git clone <этот репозиторий> && cd Agent/finpanel
   cp .env.example .env
   python3 -c "import secrets; print(secrets.token_hex(32))"   # → SECRET_KEY
   docker compose build app
   docker compose run --rm app python -m finance.security "ваш-пароль"   # → ADMIN_PASSWORD_HASH
   nano .env   # DOMAIN, SECRET_KEY, ADMIN_PASSWORD_HASH (в одинарных кавычках!), ANTHROPIC_API_KEY
   docker compose up -d
   ```
   Хеш пароля содержит символы `$`, поэтому в `.env` пишите его так: `ADMIN_PASSWORD_HASH='$2b$12$...'`.
3. Откройте `https://ваш-домен`. HTTPS-сертификат Caddy получит сам.

Данные лежат в `finpanel/data/finance.db` (SQLite). **Делайте копию этого файла**, например раз в день по cron:
```bash
0 3 * * * cp /путь/Agent/finpanel/data/finance.db /путь/backups/finance-$(date +\%F).db
```

Обновление: `git pull && docker compose up -d --build`.

## Помощник (чат)

Нужен ключ Claude API: [console.anthropic.com](https://console.anthropic.com) → `ANTHROPIC_API_KEY` в `.env`. Без ключа работает всё, кроме чата.

## Локальный запуск и тесты

```bash
cd finpanel
pip install -r requirements.txt
SECRET_KEY=dev SESSION_HTTPS_ONLY=false ADMIN_PASSWORD_HASH="$(python -m finance.security dev)" python -m finance
# http://localhost:8000, логин admin / пароль dev
python -m pytest
```
