# cryptobot — крипто-бот: бэктест и paper-trading

Автоматизация трендовой стратегии для спотового рынка (BTC/USDT, ETH/USDT и т.д.).
Только лонг, без плеча. Работа с реальными деньгами намеренно не реализована:
сначала стратегия должна доказать себя на истории и на бумаге.

## Установка

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r cryptobot/requirements.txt
```

## Стратегия

- **Вход:** быстрая EMA (20) пересекает медленную (50) снизу вверх, и RSI < 70 (не покупаем на перегреве).
- **Выход:** обратное пересечение EMA, или стоп-лосс (2×ATR), или тейк-профит (4×ATR).
- **Размер позиции:** такой, чтобы срабатывание стопа стоило 1% депозита.
- Сигнал считается на закрытии свечи, исполнение — на открытии следующей (без «заглядывания в будущее»).
- Учитываются комиссия 0.1% и проскальзывание 0.05% на каждую сделку.

## Команды

```bash
# 1. Бэктест на истории Binance (ключи не нужны)
python -m cryptobot.main backtest --symbol BTC/USDT --timeframe 4h --days 730

# 2. Подбор параметров: обучаемся на 70% истории, проверяем на оставшихся 30%
python -m cryptobot.main optimize --symbol ETH/USDT --timeframe 1h --days 730

# 3. Paper-trading на живых свечах с виртуальными деньгами
python -m cryptobot.main paper --symbol BTC/USDT --timeframe 1h

# 3б. То же, но с ордерами на тестнете Binance (фейковые деньги)
#     ключи: https://testnet.binance.vision
export EXCHANGE_API_KEY=... EXCHANGE_API_SECRET=...
python -m cryptobot.main paper --symbol BTC/USDT --timeframe 1h --testnet

# Демо без интернета
python -m cryptobot.main backtest --synthetic
```

Состояние paper-трейдера и журнал сделок лежат в `paper_state/`; после перезапуска бот продолжает с того же места.

## Как читать результат

| Метрика | Что значит | Ориентир |
|---|---|---|
| `total_return_pct` vs `buy_and_hold_pct` | обыграла ли стратегия простое «купил и держи» | должна обыгрывать с учётом риска |
| `max_drawdown_pct` | худшее падение депозита от пика | > −20% — тяжело психологически |
| `profit_factor` | прибыль / убытки | > 1.3 |
| `sharpe` | доходность на единицу риска | > 1 |
| `trades` | число сделок | < 30 — статистики мало |

**Главное правило:** смотрите на результат `optimize` на тестовом отрезке, а не на обучающем. Параметры,
подогнанные под историю, почти всегда выглядят прекрасно и почти всегда разочаровывают в будущем.

## EVEDEX

Бот торгует бессрочными фьючерсами на [EVEDEX](https://exchange.evedex.com) через официальный SDK
(`@evedex/exchange-bot-sdk`). Подпись ордеров делает код самой биржи, мост — `evedex_bridge/bridge.js`.

- Сигналы считаются по свечам той же пары с Binance (у EVEDEX нет API свечей). Если Binance недоступен — `--signal-exchange bybit` или `okx`.
- Только лонг. Стоп-лосс и тейк-профит ставятся **на бирже** сразу после входа — они сработают, даже если бот упал.
- Шорты, открытые вручную, бот не трогает. Лонг по тому же инструменту бот закроет по сигналу — не держите на нём ручных позиций.
- Ограничители: плечо по умолчанию 1x (максимум 5x), позиция не больше `--max-usd` (по умолчанию $100), риск 1% баланса на сделку.

### Установка

```bash
# Node.js 18+
cd cryptobot/evedex_bridge && npm ci && cd ../..
```

### Ключи

Безопасный вариант — one-click-trading кошелёк + API-ключ (основной ключ кошелька не нужен):
профиль → Settings → API → создать ключ; ключ one-click-trading кошелька — в настройках торговли.

```bash
export EVEDEX_API_KEY=...            # API-ключ EVEDEX
export EVEDEX_OCT_PRIVATE_KEY=0x...  # ключ one-click-trading кошелька
# или, менее безопасно: export EVEDEX_PRIVATE_KEY=0x...  (ключ основного кошелька)
```

Ключи храните только в переменных окружения или `.env`, никогда не коммитьте.

### Запуск

```bash
# Список инструментов
python -m cryptobot.main evedex-instruments --env demo

# ДЕМО (тестовые USDT — кнопка «Request Demo Funds» на бирже)
python -m cryptobot.main evedex --instrument BTCUSDT:DEMO --timeframe 1h

# РЕАЛЬНЫЙ СЧЁТ — нужны оба флага и подтверждение в консоли
python -m cryptobot.main evedex --env prod --real-money --instrument <имя из evedex-instruments> --max-usd 50
```

Журнал действий пишется в `paper_state/evedex_*.trades.csv`.

## Панель управления

Веб-страница, где видны все запущенные боты EVEDEX: баланс, позиция, PnL, стоп и тейк, сигнал,
график баланса и история сделок. Кнопки: **Пауза** (бот не открывает новые сделки, но закрывает
текущую по сигналу; стопы на бирже работают), **Продолжить**, **Закрыть позицию** (по рынку + пауза).

Бот и панель — отдельные процессы: панель можно перезапускать, не трогая сделки.

```bash
# Терминал 1 — бот
python -m cryptobot.main evedex --instrument BTCUSDT:DEMO

# Терминал 2 — панель, откройте http://localhost:8050
python -m cryptobot.main panel
```

Страница обновляется сама каждые 10 секунд. Зелёная точка — бот жив, красная — бот не отвечает.

### Панель на сервере (VPS)

Самый безопасный способ — не открывать порт наружу, а зайти через SSH-туннель:

```bash
ssh -L 8050:localhost:8050 user@ваш-сервер
# и открыть http://localhost:8050 у себя в браузере
```

Если нужен доступ с телефона напрямую — только с паролем (логин любой):

```bash
export PANEL_PASSWORD='длинный-случайный-пароль'
python -m cryptobot.main panel --host 0.0.0.0
```

Без `PANEL_PASSWORD` панель не запустится на внешнем адресе: через неё можно закрывать позиции.

## Путь к реальным деньгам

1. Бэктест на 2+ годах и нескольких монетах — стабильно лучше buy & hold по риску.
2. Paper/testnet 1–2 месяца — результаты похожи на бэктест.
3. Только потом — реальный счёт с суммой, которую не жалко потерять, и API-ключом **без права вывода**.
