# FamilyChef

Веб-приложение (PWA, работает на телефоне): пользователь вводит бюджет, состав семьи,
ограничения в питании и продукты, которые уже есть дома. В ответ он получает **меню на неделю**,
**рецепты с количествами под свою семью** и **список покупок с ценами в местной валюте**.

## Почему цены «местные», а не пересчитанные из долларов

- У каждой страны своя таблица `data/prices/<CODE>.csv` **в национальной валюте** (RUB, BYN, KZT, UZS, EUR, USD).
- Учитывается **местная фасовка**: молоко 930 мл в России и галлон в США, яйца десятком и дюжиной,
  картофель сеткой 2,5 кг в Германии. Покупки считаются **целыми упаковками**, как в магазине.
- Учитывается **местный ассортимент и соотношение цен**: в Узбекистане свинины нет в прайсе, поэтому блюда
  с ней не предлагаются; гречка в США — дорогой нишевый продукт, и планировщик её почти не ставит.
- Блюда помечены регионами, где они привычны (`popular_in`): плов и лагман чаще появляются в UZ и KZ,
  борщ и сырники — в RU и BY, чили — в US.
- **Городской коэффициент** (Москва ×1,15, Алматы ×1,07, Нью-Йорк ×1,2 и т. д.).
- **Цены пользователя**: любую цену в списке покупок можно заменить ценой своего магазина. Она сохраняется
  на устройстве, и меню **пересчитывается** (дешёвые у вас продукты будут появляться чаще).

> ⚠️ Стартовые цены — **ориентировочные оценки на ноябрь 2025 года**, собранные вручную. Перед релизом их нужно
> сверить с реальными ценами (см. «Перед запуском»).

## Как работает планировщик (`planner.py`)

1. Фильтрует рецепты: приём пищи, диета (вегетарианская, веганская, без свинины, без глютена, без молочного, без рыбы,
   пескетарианская — выводится автоматически из свойств ингредиентов), исключённые продукты, наличие в регионе.
2. Считает **реальный чек**: суммирует потребность в каждом продукте, вычитает домашние запасы,
   округляет вверх до целых упаковок и умножает на местную цену. Поэтому блюда с общими продуктами
   (один пакет моркови на плов и суп) выгоднее, и остатков меньше.
3. Оптимизирует: жадное построение + локальный поиск с несколькими стартами. Цель: уложиться в бюджет,
   при этом разнообразие (блюдо максимум 2 раза в неделю, не дважды в день), местная кухня, предпочтения
   («быстрые», «супы», «рыба», «детские»).
4. Порции: ребёнок 3–12 лет = 0,6 взрослой порции.
5. Если бюджета не хватает, выдаёт самое дешёвое меню и предупреждение.

План на неделю считается примерно за 0,1 с, без LLM и внешних API.

## Запуск

```bash
pip install -r familychef/requirements.txt
```

```bash
python -m familychef
```

Откройте http://localhost:8080 (порт задаётся через `PORT`). Тесты:

```bash
python -m pytest familychef/tests
```

Docker:

```bash
docker build -f Dockerfile.familychef -t familychef .
```

```bash
docker run -p 8080:8080 familychef
```

## Установка на сервер (одна команда)

Подходит для любого Linux-сервера, в том числе если на нём уже работают сайты или Keitaro: порты 80/443
и чужие контейнеры не затрагиваются. Зайдите на сервер по SSH под root и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/shahruh8484/Agent/claude/happy-albattani-m08fna/deploy/install-familychef.sh | sudo bash
```

Скрипт покажет, что уже есть на сервере, при необходимости поставит Docker, соберёт и запустит контейнер,
откроет порт в ufw/firewalld и напечатает ссылку. На чистом сервере приложение будет доступно по `http://IP`,
а если порт 80 занят, то на свободном порту начиная с 8090. Чтобы обновить приложение, запустите ту же команду ещё раз.

С доменом и HTTPS (A-запись домена должна указывать на IP сервера):

```bash
curl -fsSL https://raw.githubusercontent.com/shahruh8484/Agent/claude/happy-albattani-m08fna/deploy/install-familychef.sh | sudo FC_DOMAIN=familychef.ru bash
```

## Вход и личный кабинет

Пользователи могут войти **через Google** или **по коду на email**. В кабинете хранятся имя, настройки семьи,
свои цены (синхронизируются между устройствами) и 20 последних меню; там же «Выйти» и «Удалить аккаунт»
(страница `https://familychef.pro/account` — её же указывайте в Google Play как ссылку на удаление аккаунта).

Пока ни один способ входа не настроен, кнопка «Войти» не показывается и сайт работает без регистрации.
Настройки хранятся на сервере в `/opt/familychef/familychef.env`, база — в docker-томе `familychef_data`.

### Вход через Google (бесплатно)

1. Откройте https://console.cloud.google.com, создайте проект **FamilyChef**.
2. **Google Auth Platform → Branding**: название FamilyChef, email поддержки, домен `familychef.pro`,
   политика конфиденциальности `https://familychef.pro/privacy`. **Audience**: External, затем *Publish app*
   (для имени и email проверка Google не нужна).
3. **Clients → Create client → Web application**. *Authorized JavaScript origins*: `https://familychef.pro`.
   Скопируйте **Client ID** (`…apps.googleusercontent.com`).
4. **Clients → Create client → Android**: package `pro.familychef.app`, SHA-1 ключа загрузки
   `66:8B:11:F6:C1:23:D4:15:75:BB:D4:4F:54:86:4B:E3:29:5B:5D:23`. После публикации в Google Play создайте ещё один
   Android-клиент с SHA-1 *ключа подписи приложения* из Play Console (Подпись приложений).
5. На сервере:

```bash
curl -fsSL https://raw.githubusercontent.com/shahruh8484/Agent/claude/happy-albattani-m08fna/deploy/install-familychef.sh | sudo FC_DOMAIN=familychef.pro FC_GOOGLE_CLIENT_ID=ВАШ_CLIENT_ID bash
```

### Вход по email (Resend, бесплатно до 3000 писем в месяц)

1. Зарегистрируйтесь на https://resend.com, добавьте домен `familychef.pro` и внесите показанные DNS-записи
   у регистратора (GoDaddy → DNS). Дождитесь статуса *Verified*.
2. Создайте API key и запустите установщик с `FC_EMAIL_PROVIDER=resend RESEND_API_KEY=re_...`
   (ключ сохранится в `familychef.env`; чтобы он не попал в историю команд, можно вписать его в этот файл вручную).

Для проверки без почты: `FC_EMAIL_PROVIDER=dev` — код показывается на экране. **Только для тестов**: в этом
режиме войти можно в любой адрес.

### Обязательный вход

`FC_REQUIRE_LOGIN=1` — составлять меню могут только вошедшие пользователи (`0` — вход необязателен).

## Бесплатный тариф и FamilyChef Plus

| | Бесплатно | Plus |
|---|---|---|
| Меню | на 1 день, раз в неделю | на неделю, сколько угодно |
| Замена блюд, «больше не предлагать», другой вариант | — | ✅ |
| Цены своего магазина | — | ✅ |
| История меню в кабинете | последнее | 20 последних |

Ограничения проверяются на сервере (`familychef/limits.py`) и **включаются** настройкой `FC_LIMITS=1`
(по умолчанию выключены, пока нет оплаты подписки). Цифры: `FC_FREE_DAYS` (дней в бесплатном меню, 1) и
`FC_FREE_PERIOD_DAYS` (как часто, 7). Меню короче недели оценивается по стоимости продуктов на эти дни и
доле недельного бюджета, а не по целым упаковкам.

Выдать или забрать Plus вручную (например, тестировщикам):

```bash
docker exec familychef python -m familychef.admin plus someone@gmail.com 30
```

```bash
docker exec familychef python -m familychef.admin free someone@gmail.com
```

```bash
docker exec familychef python -m familychef.admin stats
```

## API

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/regions` | страны, валюты, города, ориентир бюджета |
| GET | `/api/ingredients?region=RU` | продукты с местной фасовкой и ценой |
| POST | `/api/plan` | меню, рецепты, список покупок |

Пример запроса:

```json
{"region": "KZ", "city": "ala", "budget": 30000, "adults": 2, "children": 1,
 "meals": ["breakfast", "lunch", "dinner"], "diets": ["no_pork"], "exclude": ["fish_fillet"],
 "favorites": ["soup"], "pantry": [{"ingredient": "rice", "quantity": 1500}],
 "price_overrides": {"beef": {"price": 3400}}}
```

## Как добавить страну или обновить цены

1. Добавить регион в `data/regions.json` (валюта, локаль, города с коэффициентами, ориентир бюджета).
2. Создать `data/prices/<CODE>.csv`: `ingredient,pack_size,pack_label,price`, где `pack_size` в г, мл или шт.
   Продукт, которого в стране обычно нет в продаже, просто не указывайте.
3. При желании добавить в `popular_in` местные блюда в `data/recipes.json`.
4. Запустить тесты: они проверяют целостность справочников.
