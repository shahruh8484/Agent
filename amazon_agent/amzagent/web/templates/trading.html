Бот ещё не подключён

Бот работает отдельным контейнером рядом с панелью. Чтобы включить его, добавьте в amazon_agent/.env на сервере:

COMPOSE_PROFILES=trading
TRADER_ENV=demo
TRADER_INSTRUMENT=BTCUSDT:DEMO
EVEDEX_API_KEY=…          # EVEDEX → профиль → Settings → API
EVEDEX_OCT_PRIVATE_KEY=0x… # ключ one-click-trading кошелька

Затем выполните deploy/autoupdate.sh --force (или дождитесь следующего обновления). Через минуту-две бот появится на этой странице. Начните с демо: тестовые USDT выдаёт кнопка «Request Demo Funds» на бирже. Реальный счёт включается только двумя строками: TRADER_ENV=prod и TRADER_REAL_MONEY=yes.
