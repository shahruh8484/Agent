Импорт из Creator Connections

Откройте в Associates Central страницу Creator Connections (вкладка Accepted — бонус платят только по принятым кампаниям), нажмите Ctrl+A, Ctrl+C и вставьте сюда. Агент найдёт ASIN и Estimated EPC, проверит товары на Amazon (рейтинг, отзывы, продажи) и выставит лучшие на сайт — товары с высоким EPC выше.

Правила агента

Отбор: рейтинг ≥ {{ settings.min_rating }}, отзывов ≥ {{ settings.min_reviews }}, до {{ settings.products_per_site }} товаров на сайт.
Запуск: до {{ settings.campaigns_per_site }} кампаний на сайт, ${{ "%.2f"|format(settings.campaign_daily_budget) }}/день каждая, ставка CPC ${{ settings.push_bid_cpc }}, гео {{ settings.push_countries }}; общий лимит ${{ "%.2f"|format(settings.max_daily_spend) }}/день.
Отключение: после ${{ "%.2f"|format(settings.kill_min_spend) }} расхода, если клик на Amazon дороже ${{ "%.2f"|format(settings.max_cost_per_amazon_click) }}. Площадки (зоны) с расходом ≥ ${{ "%.2f"|format(settings.zone_min_spend) }} и без кликов — в чёрный список.
