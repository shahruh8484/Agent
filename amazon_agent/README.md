# Amazon Affiliate Agent

Автономный агент, который сам:

1. **Подбирает товары на Amazon** под нишу (через официальный Creators API).
2. **Отбирает лучшие**: рейтинг, число отзывов, скидка, место в продажах.
3. **Делает сайт-витрину** под нишу: главная, страница каждого товара,
   тексты (LLM), раскрытие партнёрства. Сайт сразу доступен по
   `https://ВАШ_ДОМЕН/s/<ниша>/`.
4. **Запускает пуш-рекламу в PropellerAds** на страницы товаров своего сайта.
5. **Оптимизирует** кампании: отключает убыточные, кидает в чёрный список
   площадки без кликов, освободившийся бюджет отдаёт следующим товарам.
6. Повторяет цикл каждые `AGENT_INTERVAL_HOURS` часов.

Ниши агент тоже подбирает сам: LLM предлагает идеи, агент проверяет каждую
по реальным товарам Amazon (сколько хороших товаров, рейтинги, цены в
диапазоне $20–120) и строит сайты по лучшим. Он держит минимум
`AUTO_NICHES` сайтов (по умолчанию 3); если выключить или удалить сайт,
на его место будет подобрана новая ниша. Кнопка «Подобрать сам» в панели
запускает подбор сразу, а свою нишу по-прежнему можно добавить вручную.

## Товары из Creator Connections

Кампании Creator Connections платят бонус сверх обычной комиссии. В
Creators API нет метода, который отдаёт их список, поэтому их импортируют
вставкой: в Associates Central откройте Creator Connections → вкладка
**Accepted** (бонус платят только по принятым кампаниям) → Ctrl+A, Ctrl+C
→ в панели блок «Импорт из Creator Connections» → вставить →
«Импортировать».

Агент вытащит из текста все ASIN и их Estimated EPC, получит по API
актуальные рейтинг, отзывы, цену и место в продажах, отсеет слабые товары
и выставит до 30 лучших на отдельный сайт. Товары с высоким EPC стоят
выше, поэтому пуш-кампании в первую очередь запускаются на них. Повторный
импорт с тем же названием сайта добавляет товары в тот же сайт.

**Запасной режим без API.** Если Creators API отказывает (например,
`AssociateNotEligible` в первые 48 часов после создания ключей), агент
строит сайт из самой вставленной страницы: название, бренд, EPC; рейтинг
и число отзывов со страницы используются только для ранжирования. Фото,
цены и рейтинги на сайте не показываются — без API это запрещено
правилами Amazon, — а ссылки ведут на `amazon.com/dp/ASIN?tag=ВАШ_ТЕГ`.
Как только API заработает, агент сам заменит такие страницы полноценными
и перепишет тексты.

«Up to $2.50» — это верхняя оценка Amazon, а не гарантия, поэтому EPC
учитывается в ранжировании вместе с отзывами и продажами, а не вместо них.

## Как устроен цикл

```
каждые N часов, для каждой ниши:
  Creators API: поиск (20 товаров) ─► отбор (рейтинг ≥ 4.0, отзывов ≥ 100, есть цена и фото)
                                   ─► топ-12 на сайт, тексты от LLM для новых товаров
затем по всем кампаниям:
  PropellerAds: расход ─► правило отключения ─► чёрный список зон ─► новые кампании в пределах лимита
```

Путь посетителя: пуш → страница товара на **вашем** сайте
(`/s/<ниша>/p/<ASIN>?c=<кампания>&z=<зона>`) → кнопка «Check price on Amazon»
→ `/go/...` (клик записывается) → Amazon с вашим партнёрским тегом.

Amazon не передаёт конверсии обратно, поэтому агент оптимизирует по
**стоимости клика на Amazon**: расход кампании / клики с сайта на Amazon.

## Картинки для пушей

При `PUSH_CREATIVES=ai` (по умолчанию) агент для каждой кампании:
1. просит LLM описать `PUSH_CREATIVE_VARIANTS` разных фото-сцен по типу
   товара (без брендов, логотипов, текста и фото с Amazon — их в рекламе
   использовать нельзя);
2. рисует их через OpenAI (`OPENAI_IMAGE_MODEL`, по умолчанию `gpt-image-1`,
   качество `OPENAI_IMAGE_QUALITY`) — примерно $0.05 за картинку;
3. режет каждую на картинку пуша 492×328 и иконку 192×192;
4. кладёт все варианты в одну кампанию — сеть сама крутит их и чаще
   показывает лучший.

Если генерация не удалась (нет ключа, не пройдена верификация организации
в OpenAI, лимиты), агент пишет об этом в журнал и берёт простые картинки —
запуск не останавливается. Превью картинок видно в таблице кампаний;
кнопка «Перерисовать» делает новые для тестовой кампании.

## Защита бюджета

Бюджеты, лимиты, ставку, страны, правила отключения и включение рекламы
можно менять в панели: «⚙ Настройки рекламы и бюджета». Значения из
панели хранятся в базе и перекрывают `.env`, применяются без перезапуска.
Новый бюджет кампании применяется и к уже запущенным; если общий лимит
снизили ниже текущего расхода, агент остановит самые новые кампании.

| Правило | Настройка | По умолчанию |
|---|---|---|
| Тестовый режим: ничего не отправляется в PropellerAds | `PUSH_LIVE` | `false` |
| Общий лимит суммы дневных бюджетов всех активных кампаний | `MAX_DAILY_SPEND` | $30 |
| Бюджет одной кампании в день | `CAMPAIGN_DAILY_BUDGET` | $10 |
| Кампаний на один сайт | `CAMPAIGNS_PER_SITE` | 3 |
| Отключить кампанию, если после $X расхода клик на Amazon дороже $Y | `KILL_MIN_SPEND`, `MAX_COST_PER_AMAZON_CLICK` | $5, $0.40 |
| Зона с расходом ≥ $Z и 0 кликов → чёрный список | `ZONE_MIN_SPEND` | $1 |
| Кнопка «Стоп всё» в панели | — | — |

Товар, кампанию по которому отключило правило (или вы вручную), агент
больше не запускает повторно.

## Что нужно получить

| Что | Где | Нюанс |
|---|---|---|
| Аккаунт Amazon Associates + tracking ID (`xxx-20`) | affiliate-program.amazon.com | — |
| Creators API credentials **версии 3.x** | Associates Central → Tools → Creators API | PA-API 5 закрыт 15 мая 2026. Доступ к API обычно открывается только после первых квалифицированных продаж; credentials 2.x перестают работать после 11 сентября 2026 |
| Токен PropellerAds SSP API | ssp.propellerads.com → Profile | API открывают после $1000 расхода/депозита |
| Ключ LLM | console.anthropic.com (или OpenAI) | — |
| Сервер + домен | любой VPS с Docker | A-запись домена на IP сервера |

## Запуск

```bash
cd amazon_agent
cp .env.example .env
python -m amzagent.security "ваш-пароль"                 # -> ADMIN_PASSWORD_HASH
python -c "import secrets; print(secrets.token_hex(32))"  # -> SECRET_KEY
# заполните .env: ключи Amazon, PropellerAds, LLM, DOMAIN

docker compose up -d --build
```

На `https://ВАШ_ДОМЕН/` — публичная главная со всеми сайтами агента.
Панель управления — `https://ВАШ_ДОМЕН/admin`: войдите, добавьте нишу. Агент сразу
соберёт сайт и **тестовые** кампании.

### Перед включением реальной рекламы

1. Откройте в панели payload любой тестовой кампании.
2. Сверьте его с актуальной документацией PropellerAds:
   https://ssp-api.propellerads.com/v5/docs/ — названия полей и пути
   собраны в одном месте: `amzagent/push/propeller.py` (константы вверху и
   `build_campaign_payload`). Из среды разработки документация была
   недоступна, поэтому эту сверку нужно сделать один раз вручную —
   особенно формат креативов (иконка/картинка как URL или загрузка файла)
   и макросы `${ZONEID}` / `${SUBID}` в ссылке.
3. Поставьте `PUSH_LIVE=true` и перезапустите: `docker compose up -d`.
   Тестовые кампании будут закрыты, и агент запустит настоящие.

Локально без Docker:

```bash
pip install -r requirements.txt
SESSION_HTTPS_ONLY=false python -m amzagent.web   # http://localhost:8000
pytest                                            # тесты, полностью офлайн
```

## Правила Amazon, которые агент соблюдает

- Страницы, которые проверяет Amazon при ревью сайта: `/about`, `/contact`
  (форма связи — сообщения видны в панели), `/privacy` (с обязательным
  пунктом о cookies Amazon и третьих сторон), `/terms`,
  `/affiliate-disclosure`; ссылки на них в подвале каждой страницы. Плюс
  `/sitemap.xml`, `/robots.txt`, значок сайта. `CONTACT_EMAIL` в `.env`
  добавит email на страницы Contact и Privacy.

- На каждой странице — раскрытие «As an Amazon Associate we earn from
  qualifying purchases».
- Цена показывается только если получена из API менее 24 часов назад, с
  датой и обязательной оговоркой; устаревшая цена скрывается. Поэтому
  держите `AGENT_INTERVAL_HOURS` ≤ 24.
- Картинки товаров подгружаются с серверов Amazon, не копируются.
- В рекламе **нет** прямых партнёрских ссылок и фото товаров Amazon: пуш
  ведёт на ваш сайт, а картинки креативов агент рисует сам
  (`amzagent/push/creatives.py`).
- Тексты не содержат цен, скидок, выдуманных характеристик и срочности
  (жёсткие правила в промптах `amzagent/content/writer.py`).

Риск, о котором стоит знать: пуш-трафик дешёвый, но низкого качества.
Amazon следит за качеством трафика и может закрыть аккаунт Associates при
большом числе кликов без покупок. Начинайте с маленького лимита и
смотрите отчёт по заработку в Associates Central.

## Структура

```
amzagent/
├── amazon/catalog.py      Creators API: поиск и получение товаров
├── amazon/creator_connections.py  разбор вставленной страницы Creator Connections
├── selection/selector.py  фильтр и ранжирование товаров
├── selection/niches.py    автоподбор ниш (идеи LLM + проверка по Amazon)
├── content/               LLM и генерация текстов (сайт + пуши)
├── push/propeller.py      PropellerAds SSP API v5
├── push/creatives.py      простые иконка и картинка для пуша (Pillow)
├── push/ai_creatives.py   картинки для пушей нейросетью (OpenAI)
├── agent/runner.py        автономный цикл и правила бюджета
├── store.py               SQLite: ниши, товары, кампании, события, журнал
├── site/templates/        шаблоны публичных сайтов
└── web/                   FastAPI: сайты, трекинг, панель управления
```
