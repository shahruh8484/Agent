# Dasturxon — админ-панель

Веб-панель для владельца, бухгалтера и поддержки (раздел 7 ТЗ). React 18 + TypeScript + Vite, Ant Design 5, Recharts, Socket.io.

## Запуск

Нужен Node.js 18+ и запущенный backend (`../backend`, по умолчанию `http://localhost:4000`).

```bash
cd admin
npm install
npm run dev        # http://localhost:5173
```

Сборка и просмотр собранной версии:

```bash
npm run build      # проверка типов (tsc) + сборка в dist/
npm run preview    # http://localhost:4173
```

`dist/` — статические файлы, их можно отдавать любым веб-сервером (nginx и т. п.). Все пути SPA нужно перенаправлять на `index.html`.

## Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `VITE_API_URL` | `http://localhost:4000` | Адрес backend без `/api`. Используется и для REST, и для Socket.io (`/socket.io`). |

Переменные задаются в `.env` / `.env.local` (пример — `.env.example`) или при запуске: `VITE_API_URL=https://api.dasturxon.uz npm run build`. Значение подставляется на этапе сборки.

На backend должен быть разрешён CORS для адреса панели (`CORS_ORIGIN`, по умолчанию `*`).

## Вход

Демо-доступы (после `npm run seed` в backend):

| Роль | Email | Пароль |
|---|---|---|
| Владелец | owner@dasturxon.uz | admin12345 |
| Бухгалтер | accountant@dasturxon.uz | accountant123 |
| Поддержка | support@dasturxon.uz | support123 |

Токены хранятся в `localStorage`. При ответе 401 панель один раз пробует `POST /api/auth/refresh`, при неудаче — выходит на экран входа.

## Разделы и права

| Раздел | Владелец | Бухгалтер | Поддержка |
|---|---|---|---|
| Дашборд | полностью | полностью | без денежных показателей и блока выплат |
| Заказы, карточка заказа | ✓ + возвраты/отмена | просмотр | ✓ + возвраты до 50 000 сум |
| Повара, профиль повара | ✓ | только финансы | ✓, блокировка до 24 ч |
| Верификация | ✓ | — | ✓ |
| Покупатели | ✓ + блокировка | — | просмотр |
| Жалобы | ✓ | — | ✓ |
| Выплаты (история, запуск, досрочные выводы) | ✓ | ✓ | — |
| Финансы, Excel-отчёты | ✓ | ✓ | — |
| Сотрудники, Настройки, Журнал действий | ✓ | — | — |

Пункты меню и кнопки скрываются по `permissions` сотрудника (`/api/admin/me`); backend проверяет права независимо.

## Живые обновления

Панель подключается к Socket.io с access-токеном сотрудника. События `order:update`, `alert`, `payouts:done` обновляют открытые страницы и счётчики в меню; на `alert` показывается уведомление (клик открывает связанную страницу).

## Структура

```
src/
  api.ts            HTTP-клиент, refresh токенов, скачивание файлов, хук useApi
  auth.tsx          вход/выход, права
  realtime.tsx      Socket.io, уведомления, хук useLive
  format.ts         деньги («1 247 500 сум»), даты (Asia/Tashkent), подписи статусов
  components/       оболочка с меню, общие модалки (возврат, блокировка)
  pages/            страницы разделов
```
